# 📊 Excel for Data Analytics 

This project uses data from Data Nerd, a website owned by Luke Barousse, containing approximately 22,000 job postings from 2023. The project approaches data analysis from a job candidate’s perspective, using job-market data to understand the skills, tools, and salaries associated with different data-related roles across countries.

The course progresses from fundamental Excel functions to advanced data-analysis techniques, covering topics such as Power Query, Power Pivot, DAX, measures, data transformation, and visualization.

## Dataset Highlights
- Dataset Job posting from Datanerd.tech

- Columns used : Job title short, Job title, Job location, Job via, Job schedule type, Job work from home, search location, Job posted date, Job no degree mention, Job health insurance, Job country, Salary rate, Salary year avg, Salary hour avg, Company name, Job skills

- Records : Approx. 21,600 job posting from the year 2023.
